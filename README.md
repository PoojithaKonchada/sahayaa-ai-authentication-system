# SAHAYAA – Web-Based AI Secured User Authentication System

## Overview
SAHAYAA is an AI-powered secure authentication and donation platform developed using React.js and Strapi.

## Features
- AI-based login monitoring
- Secure authentication
- Donation tracking
- Campaign management
- Payment integration
- Real-time notifications

## Technologies Used
- React.js
- Strapi CMS
- JavaScript
- REST APIs
- AI/ML Concepts
